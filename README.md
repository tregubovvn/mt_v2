## 📖 Описание

**Moodle XML Тестирование с формулами** — это клиентское (frontend-only) приложение, которое позволяет:

- Загружать тесты, экспортированные из LMS **Moodle** в формате XML;
- Проходить их в удобном интерфейсе с вопросами типа «множественный выбор» (`multichoice`);
- Корректно отображать **математические формулы LaTeX** внутри вопросов и вариантов ответов;
- Отслеживать время прохождения и получать подробные результаты.

Приложение полностью работает **в браузере** — не требует серверной части, базы данных или установки. Все вычисления и рендеринг выполняются локально на устройстве пользователя.

## ✨ Возможности

### 📥 Загрузка тестов
| Способ | Описание |
|---|---|
| 🔗 **Прямая ссылка** | Введите URL на XML-файл и нажмите «Загрузить тест» |
| 📷 **QR-код** | Наведите камеру на QR-код со ссылкой — адрес вставится автоматически |
| ☁️ **Яндекс.Диск** | Укажите публичную ссылку на файл с Яндекс.Диска (`yadi.sk` / `disk.yandex`) |
| 🔗 **GET-параметр** | Передайте ссылку в URL страницы: `?name=https://example.com/test.xml` |

### 🧪 Прохождение теста
- Вопросы выводятся **по одному** с навигацией «Назад / Вперёд»;
- **Таймер** прохождения в формате `ЧЧ:ММ:СС`;
- Счётчик «Вопрос X из Y»;
- Подсветка выбранного варианта ответа.

### 📐 Формулы
- Рендеринг LaTeX-формул через **MathJax 3**;
- Поддержка строчных формул: `\( ... \)`;
- Поддержка выносных формул: `\[ ... \]`;
- Формулы работают как в тексте вопросов, так и в вариантах ответов и результатах.

### 📊 Результаты
- Итоговый процент правильных ответов;
- **Оценка по 5-балльной шкале** (автоматический расчёт);
- Затраченное время;
- **Подробный разбор**: каждый вопрос, ваш ответ, правильный ответ и статус (✓ / ✗).

### 📱 Адаптивность
- Полностью адаптивный дизайн (media queries) для смартфонов и планшетов;
- Поддержка мобильных браузеров, включая фронтальную/заднюю камеру для сканирования QR.

## 🚀 Установка и запуск

Приложение — это **один HTML-файл**. Никакой сборки, зависимостей или сервера не требуется.

### Вариант 1: Открыть локально
1. Скачайте или склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/moodle-xml-quiz.git
   cd moodle-xml-quiz
   ```
2. Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).

### Вариант 2: Локальный сервер (рекомендуется)
Некоторые браузеры ограничивают работу камеры и `fetch` при открытии файла через `file://`. Для полноценной работы запустите простой сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Затем откройте: `http://localhost:8000`

### Вариант 3: GitHub Pages
1. Загрузите файл в репозиторий;
2. В настройках репозитория включите **Settings → Pages → Deploy from branch**;
3. Приложение будет доступно по адресу `https://ваш-username.github.io/имя-репозитория/`.

> ⚠️ **Важно:** сканирование QR-кодов требует **HTTPS** или `localhost` (ограничение MediaDevices API браузеров).

## 📲 Использование

1. **Загрузите тест** одним из способов (см. ниже);
2. Пройдите тест — выбирайте ответы и переключайтесь между вопросами кнопками «Предыдущий вопрос» / «Следующий вопрос»;
3. На последнем вопросе нажмите **«Завершить тест»**;
4. Просмотрите результаты: процент, оценку, время и детальный разбор каждого вопроса;
5. При необходимости нажмите **«Пройти тест снова»**.

### Способы загрузки теста

#### 🔗 По прямой ссылке
Введите URL XML-файла в поле и нажмите **«Загрузить тест»** (или Enter).

> ⚠️ Файл должен быть доступен с разрешением **CORS**, иначе браузер заблокирует запрос. Ссылки Moodle должны открывать файл «для гостей» без авторизации.

#### 📷 Через QR-код
1. Нажмите кнопку **«QR-код»**;
2. Разрешите доступ к камере;
3. Наведите камеру на QR-код, содержащий ссылку на XML-файл;
4. Ссылка автоматически вставится в поле ввода, сканер закроется.

> 💡 Сгенерировать QR-код со ссылкой на свой тест можно любым онлайн-генератором (например, [qrcode-monkey](https://www.qr-code-generator.com/)).

#### ☁️ С Яндекс.Диска
1. Опубликуйте XML-файл на Яндекс.Диске («Поделиться» → скопировать ссылку);
2. Вставьте публичную ссылку (вида `https://yadi.sk/i/...`) в поле ввода;
3. Нажмите **«Яндекс.Диск»**.

Приложение через публичный API Яндекс.Диска само получит прямую ссылку на скачивание и загрузит файл.

#### 🔗 Через GET-параметр
Можно сразу передать ссылку на тест в адресной строке:
```
https://ваш-сайт/?name=https://example.com/test.xml
```
Ссылка автоматически подставится в поле ввода при загрузке страницы.

## 📄 Формат файла теста

Приложение работает с экспортом тестов Moodle (формат **Moodle XML**). Поддерживаются:

- Тип вопроса: **`multichoice`** (множественный выбор) — единственный поддерживаемый тип;
- Текст вопроса и вариантов ответов в формате HTML (включая `<![CDATA[ ... ]]>`);
- LaTeX-формулы в нотации `\( ... \)` и `\[ ... \]`;
- Атрибут `fraction` у ответа — значение больше `0` означает правильный ответ.

### Структура вопроса

```xml
<question type="multichoice">
    <name>
        <text>Название вопроса</text>
    </name>
    <questiontext format="html">
        <text><![CDATA[<p>Текст вопроса с формулой \(E = mc^2\)</p>]]></text>
    </questiontext>
    <answer fraction="100">
        <text><![CDATA[Правильный ответ]]></text>
    </answer>
    <answer fraction="0">
        <text><![CDATA[Неправильный ответ]]></text>
    </answer>
</question>
```

| Элемент / атрибут | Описание |
|---|---|
| `<question type="multichoice">` | Вопрос с выбором одного варианта |
| `<questiontext>` | Текст вопроса (HTML внутри CDATA) |
| `<answer fraction="N">` | Вариант ответа; `fraction > 0` — правильный |
| `\( формула \)` | Строчная LaTeX-формула |
| `\[ формула \]` | Выносная LaTeX-формула |

## 🧮 Пример XML-файла

В приложении есть встроенный демо-тест из 3 вопросов с формулами:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<quiz>
    <question type="multichoice">
        <name><text>Пример с формулой 1</text></name>
        <questiontext format="html">
            <text><![CDATA[<p>Выберите правильную формулу для расчета коэффициента:</p>
            <p>\(\alpha_{\text{н}} = \frac{\text{АД}_{\text{сэ}}}{\text{АД}_{\text{с}}}\)</p>]]></text>
        </questiontext>
        <answer fraction="100">
            <text><![CDATA[\(\alpha_{\text{н}} = \frac{\text{АД}_{\text{сэ}}}{\text{АД}_{\text{с}}}\)]]></text>
        </answer>
        <answer fraction="0">
            <text><![CDATA[\(\alpha_{\text{н}} = \frac{\text{АД}_{\text{с}}}{\text{АД}_{\text{сэ}}}\)]]></text>
        </answer>
        <answer fraction="0">
            <text><![CDATA[\(\alpha_{\text{н}} = \text{АД}_{\text{сэ}} + \text{АД}_{\text{с}}\)]]></text>
        </answer>
    </question>
    <!-- остальные вопросы аналогично -->
</quiz>
```

## 🎓 Система оценивания

| Метрика | Как считается |
|---|---|
| **Процент** | `(правильные ответы / всего вопросов) × 100%`, округление до целого |
| **Оценка** | `⌈(правильные ответы / всего вопросов) × 5⌉` — по 5-балльной шкале |

Пример: 7 правильных из 10 → 70% → оценка 4.

## Режим мгновенной проверки ответов (CheckMode)

Приложение поддерживает режим тренажёра с мгновенной проверкой ответов. В обычном режиме тестирование проходит как обычно, а результат становится известен только после завершения. В режиме **CheckMode** студент сразу видит, правильно ли он ответил на каждый вопрос.

### Как включить

Добавьте параметр `CheckMode=true` в адресную строку:

```
index.html?url=https://example.com/test.xml&CheckMode=true
index.html?name=https://example.com/test.xml&CheckMode=1
```

Регистр имени параметра не важен (`checkmode`, `CheckMode`, `CHECKMODE` — всё сработает). Принимаемые значения: `true`, `1`, `yes`.

Если параметр не указан, приложение работает в стандартном режиме без изменений.

### Возможности режима

- **Кнопка «🔍 Проверить»** — появляется под вариантами ответа у каждого вопроса и активируется после выбора ответа.
- **Мгновенная обратная связь** — по нажатию кнопки:
  - выбранный неверный ответ подсвечивается красным;
  - правильный ответ всегда подсвечивается зелёным;
  - выводится плашка «✓ Верно!» или «✗ Неверно»;
  - при ошибке отображается текст правильного ответа (формулы LaTeX рендерятся через MathJax).
- **Фиксация ответа** — после проверки изменить ответ на вопросе нельзя. Это исключает перебор вариантов до правильного.
- **Случайный порядок вопросов** — при каждом запуске теста (в том числе после «↻ Пройти тест снова») вопросы перемешиваются алгоритмом Фишера–Йетса.
- **Восстановление состояния** — при возврате к уже проверенному вопросу (кнопка «← Назад») результат проверки сохраняется и отображается снова.

### Итоговые результаты

Подсчёт результатов в режиме CheckMode не отличается от обычного: по завершении теста выводится процент правильных ответов, оценка, статистика и детальный разбор каждого вопроса. При этом порядок вопросов в результатах соответствует порядку, в котором они шли в тесте (перемешанному).

### Рекомендуемое применение

| Сценарий | Параметры |
|---|---|
| Контрольная работа / экзамен | `?url=...` |
| Тренажёр для самоподготовки | `?url=...&CheckMode=true` |

> **Примечание:** режим CheckMode предназначен для тренировки и самопроверки. Для оценивания используйте обычный режим, так как мгновенная обратная связь снижает достоверность результатов.

## ⚠️ Ограничения и известные проблемы

- **Только тип `multichoice`** — другие типы вопросов Moodle (true/false, shortanswer, essay и т.д.) пропускаются;
- **CORS**: прямая загрузка по URL возможна только если сервер отдаёт заголовки `Access-Control-Allow-Origin`. Ссылки Moodle могут требовать настройки «доступен для гостей без пароля»;
- **Камера и HTTPS**: QR-сканер работает только на `https://` или `localhost`;
- **Яндекс.Диск**: файл должен быть опубликован (публичная ссылка);
- **Один правильный ответ**: логика учитывает любой вариант с `fraction > 0` как правильный; несколько верных вариантов с частичными баллами не поддерживаются;
- Внешние библиотеки (MathJax, jsQR) загружаются **с CDN** — при первом запуске нужен доступ в интернет.

## ❓ Часто задаваемые вопросы

**Формулы не отображаются. Что делать?**
Убедитесь, что формулы обёрнуты в `\( ... \)` и что XML корректно экранирует обратные слэши (в CDATA этого делать не нужно). Проверьте консоль браузера (F12) на ошибки MathJax.

**Ошибка 403 при загрузке по ссылке.**
Сервер блокирует запрос или требует авторизацию. Для файлов Moodle включите гостевой доступ или используйте Яндекс.Диск.

**Ошибка 404 с Яндекс.Диска.**
Файл не опубликован или ссылка устарела. Переопубликуйте файл и скопируйте актуальную ссылку.

**Камера не запускается.**
Разрешите доступ к камере в настройках браузера. На HTTP-сайтах (кроме localhost) камера недоступна — используйте HTTPS.

**Как экспортировать тест из Moodle?**
В курсе Moodle: *Банк вопросов → Экспорт → формат «Формат Moodle XML» → скачать файл*.
