Публикация и сохранение

Автосохранение на диск компьютера включается переключателем рядом с кнопкой «💾 Сохранить в файл» и срабатывает только при изменениях в задании.

Публикация выполняется только кнопкой «🚀 Публикация» (GitHub Gist или GitVerse) — после публикации возвращается ссылка на тест. Флаги CheckMode / ShowHeader / CrushMode / RandomMode рядом с кнопкой «Открыть тест» подставляются в ссылку на тест. CheckMode только включает кнопку «Проверить ответ» на каждом вопросе (в любом режиме); случайный порядок вопросов задаётся флагом RandomMode.

Загрузить из GitHub Gist

Можно вставить ссылку на задание, raw-ссылку или просто ID Gist.

Промпты DeepSeek

Все промпты хранятся в одном GitHub Gist в формате Markdown (каждый — секция «## название»). Промпты из Gist помечены значком ☁; свои добавляются кнопкой «+ Новый промпт».

    «Сохранить все в Gist» требует GitHub Token (⚙ Настройки) и права записи gist. Если ссылка на Gist не указана — создаётся новый Gist, а его ссылка запоминается.
